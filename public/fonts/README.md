# Local fonts

Inter and Outfit are served by this site to avoid an automatic visitor connection
to Google Fonts. Both are licensed under the SIL Open Font License 1.1; the
unmodified licence files in this directory accompany the fonts.

Downloaded 26 October 2026 from Google's official fonts repository:

- Inter: https://github.com/google/fonts/tree/main/ofl/inter
- Outfit: https://github.com/google/fonts/tree/main/ofl/outfit

The variable fonts cover the weights used by the existing design. Keep these
licences with redistributed copies. No external font stylesheet is required.
